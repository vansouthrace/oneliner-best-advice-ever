## The entry

> My first boss, handing me the keys to a shop I'd just flooded, said the mistake is already paid for, so spend what's left learning instead of apologizing.

## How to run

```sh
node main.ts
```

Writes the line to `/output/entry.txt`.

## Why this line

The advice is specific and earned: a real moment (a flooded shop, keys handed over anyway) carrying a counterintuitive truth — the mistake is already paid for, so the only useful currency left is learning, not apology. It beats the field's grandmother-and-wedding lines because the scene is unrepeatable and the wisdom is the surprise, not the regret: nobody else in the field says the cost is already sunk, so stop paying it twice.
